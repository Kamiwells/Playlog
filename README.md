# Playlog

A simple game tracker built to learn React fundamentals — keep track of games you're playing, have finished, or ditched along the way.

## Features

- Add games with a name and status (Backlog, Playing, Completed, Abandoned)
- Filter your list by status
- Delete games you no longer want to track
- Your list is saved automatically, so it's still there when you come back

## Tech Stack

- React + Vite
- Tailwind CSS
- Browser localStorage for persistence

## Running Locally

```bash
npm install
npm run dev
```
